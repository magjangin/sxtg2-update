# 코드 리뷰 2026-11-16 — 업데이트 지문 비교와 점검 결과 한 줄

요청: 개선점 찾기, 문서화 강화, 업데이트 내성 강화, 커밋·푸시·머지·청소. 빌드 `26455233`.

## 1. 찾은 개선점

| 구분 | 발견 | 조치 |
| --- | --- | --- |
| 업데이트 감지 | `UpdateGuard`는 `.acf` buildid와 `GameAssembly.dll` 크기를 소스에 박힌 "검증 목록"과만 비교함. 새 빌드는 목록에 없어서 "검증 안 됨"만 알 수 있고, **무엇이 바뀌었는지**(특히 `global-metadata.dat`/`UnityPlayer.dll`)는 모름. 메타데이터가 바뀌면 인터롭 형식·필드 오프셋이 달라질 수 있어 `GameAssembly.dll`만 바뀐 11-06 업데이트보다 위험함 | 지난 실행의 파일 크기 지문과 비교(아래 2장) |
| 결과 파악 | 패치 결과(`패치 N개 적용…`), 필수 패치 빠짐, 빌드 경고가 서로 다른 줄에 흩어져 있어 "그래서 지금 괜찮은가"를 로그에서 한 번에 알기 어려움 | 부팅 끝에 `[UpdateGuard] 업데이트 점검 결과:` 한 줄(정상 / 일부 빠짐 / 필수 빠짐 / 검증 안 됨) |
| 시험 | 지문 비교 같은 순수 로직을 시험할 곳이 없었음 | `Managers/BuildFingerprint.cs`(MelonLoader 무관 순수 함수)로 분리, `tools/lambdascan`에 7건 추가 |

이번에 **고치지 않은 것**: 레거시 훅 24개 제거(11-15 결론 유지), Harmony 3초(패치당 고정 비용), 곡 선택 MAX COMBO(원인 미확인). 코드 전반의 `TODO`/`FIXME`는 0건, 빈 `catch`는 33곳으로 모두 시작·로그·파일 정리 같은 "실패해도 계속"이 의도인 자리(이번에는 건드리지 않음).

## 2. 업데이트 지문 비교 (`UpdateGuard` + `BuildFingerprint`)

- 시작할 때 `{게임}\UserData\SixtarGateMod.BuildState.txt`(key=value)를 읽어 지금 값과 비교: `buildId`, `GameAssembly.dll` 크기, `*_Data\il2cpp_data\Metadata\global-metadata.dat` 크기, `UnityPlayer.dll` 크기.
- 달라졌으면 `[UpdateGuard] 지난 실행과 달라진 것: … 크기 A → B`. **메타데이터나 UnityPlayer가 바뀌었으면** 추가 경고로 `check_update.ps1`을 돌리라고 안내.
- 한쪽을 못 읽었으면(`?`) 그 항목은 비교하지 않음(매니페스트 없는 설치, 옛 기록에 없는 항목).
- **저장 시점:** 패치가 전부 붙고 필수 패치가 안 빠졌을 때만(`ReportPatchSummary`). 일부가 빠진 상태를 정상 기준으로 기록하면 다음 부팅에서 경고가 사라지기 때문. 임시 파일에 쓰고 바꿔치기. 지우면 다음 실행에 처음부터 기록(첫 실행 안내가 한 줄 나옴).
- **한계:** 크기 비교라서 크기가 같은 변경은 못 잡음(`.acf` buildid·`LambdaTranslator` 지문이 보완). 지문은 "모드가 정상 동작을 본 마지막 상태"가 아니라 "패치가 전부 붙었던 마지막 상태"임 — 동작 확인은 여전히 커스텀 곡 1곡 플레이.

## 3. 점검 결과 한 줄

`PatchResilience.ApplyAllPatches` 끝에서 `UpdateGuard.ReportPatchSummary(적용, ICF 건너뜀, 사전 JIT 건너뜀, 실패, 필수 빠짐)`:

| 상황 | 수준 | 문구 |
| --- | --- | --- |
| 필수 패치 빠짐 | 경고 | `문제 있음: 필수 패치 N개가 빠졌습니다 …` |
| 일부 패치 빠짐 | 경고 | `일부 패치 빠짐 (ICF a, 사전 JIT b, 실패 c)` |
| 검증 안 된 빌드 또는 지문 변경, 패치는 전부 붙음 | 경고 | `패치는 전부 붙었지만 … 커스텀 곡 1곡을 결과 화면까지 플레이` (+ 달라진 것) |
| 검증된 빌드, 지문 그대로, 전부 적용 | 일반 | `정상 (검증된 빌드, 패치 전부 적용)` |
